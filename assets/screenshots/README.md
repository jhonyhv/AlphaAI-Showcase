# Galeria de demonstração

Esta pasta receberá capturas reais da aplicação preparadas para apresentação pública.

## Imagens planejadas

| Arquivo | Tela |
|---|---|
| `inicio.png` | Visão geral e próximo passo |
| `aprender.png` | Jornada, missões e progresso |
| `calculadora.png` | Simulação financeira educativa |
| `meu-plano.png` | Prioridade financeira ativa |
| `assistant.png` | Conversa com o Alpha Assistant |
| `mercado.png` | Gráficos e indicadores de estudo |

## Padrão recomendado

- resolução mínima de 1440 × 900;
- utilizar dados fictícios;
- ocultar nomes, valores e informações pessoais;
- manter o mesmo tema visual em todas as imagens;
- recortar áreas vazias do navegador;
- preferir PNG para preservar textos e gráficos.

Depois que as imagens forem adicionadas, elas serão exibidas no README principal em uma galeria de duas colunas.
