# Roadmap público do AlphaAI

Este roadmap apresenta a direção do produto em alto nível. Detalhes internos de implementação permanecem no repositório privado.

## Base já construída

- [x] perfil de aprendizado e onboarding por objetivo;
- [x] jornadas, missões, progresso e conquistas;
- [x] calculadora para reserva, metas e crescimento;
- [x] prioridade financeira acompanhada em **Meu plano**;
- [x] Alpha Assistant com contexto local;
- [x] mercado, indicadores, gráficos e ranking;
- [x] carteira local e alertas educativos;
- [x] persistência local e isolamento de dados pessoais;
- [x] testes automatizados e pipeline de qualidade.

## Em desenvolvimento

- [ ] ampliar as jornadas de educação financeira;
- [ ] melhorar a orientação do próximo passo;
- [ ] refinar a experiência em telas menores;
- [ ] revisar textos e explicações financeiras;
- [ ] preparar dados de demonstração sem informações pessoais;
- [ ] publicar capturas reais das principais telas;
- [ ] produzir um vídeo curto de apresentação.

## Próximas possibilidades

- [ ] demonstração pública limitada;
- [ ] relatórios educativos de evolução;
- [ ] novos simuladores e ferramentas de planejamento;
- [ ] expansão do catálogo de conteúdos;
- [ ] acessibilidade e navegação por teclado;
- [ ] avaliação de uma versão web ou mobile.

## Critérios de prioridade

Uma funcionalidade entra no produto quando contribui para pelo menos um destes objetivos:

1. tornar um conceito financeiro mais fácil de entender;
2. ajudar o usuário a transformar aprendizado em ação;
3. reduzir excesso de informação ou ambiguidade;
4. preservar privacidade e segurança;
5. melhorar confiabilidade, testes ou manutenção.
